# Assess a saved opportunity

Build one private, evidence-backed proposal assessment from an authenticated
saved posting and explicitly selected local preference and experience records.
The assessment is an ordinal fit explanation: it names supporting evidence,
gaps, hard blockers and focused questions, and suggests resume emphasis without
generating a resume, cover letter, or application. It does not submit,
finalize, or mark an opportunity applied. Inputs are sealed before invocation;
the model cannot establish source authority or invent lineage.
