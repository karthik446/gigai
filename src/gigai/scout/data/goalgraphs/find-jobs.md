# Find jobs

First read the [shared handoff rules](README.md). Select the user's saved
preferences explicitly and ask about material unknown constraints. Hard
constraints and soft preferences are different. Keep the user's sponsorship
need, employer sponsorship evidence and eligibility facts separate, each scoped
to its relevant country/employer/role and each capable of being unknown.

Use the invoking agent's authorized research tools or supplied postings. Save
dated exact posting snapshots, stable opportunity identity, employer/title,
source status, fit reasons, gaps and exclusions. Associate repeated discoveries
with the existing opportunity without erasing older snapshots. An identical
title is not sufficient proof that two opportunities are the same.

Explain matches against selected preference revisions and candidate evidence.
Distinguish unverified, stale and conflicting compensation/sponsorship facts.
Unknown is not yes; missing salary is not a promise. Do not claim a complete
market search or an active vacancy without dated evidence.

Hand off one composite discovery packet containing dated posting snapshots,
shortlist, exclusions and useful questions, including honest no-match results.
Selecting an opportunity pins a posting revision;
it does not apply or start tailoring. Allow a supplied posting to bypass this
goal entirely.
