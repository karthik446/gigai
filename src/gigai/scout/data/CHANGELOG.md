# Scout source changelog

## 1.2 — v0.1.7 discovery candidate

Find jobs now emits one fixed, schema-bound discovery packet. Its packaged
validator is pinned separately from the historical research candidate; this
remains an offline candidate until public caller and release gates are met.

## 1.1 — v0.1.7 research candidate

Research uses an explicit role-only Plan request and one composite evidence
packet with exact source bytes and reusable sections. Its inert source is
inventoried separately from the closed CRUD tool directory. The output
contract pins the domain schema and fixed validator source. This remains a
candidate: integration, installed workflow and release acceptance are pending.

## 1.0 — v0.1.7 candidate

Five selectable job-search goals, explicit document handoffs and a small local
report template. This source entry is a candidate, not evidence of completed
domain behavior or release-ready initialization. User-specific changes belong
to the instance history and must survive future template update decisions.
