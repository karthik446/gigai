# TD-0009 — v0.1.5 product-readiness gate

- Status: Open; release gate
- Discovered during: G26/G27 sequencing review, 2026-08-16
- Owning lane: G28 before G24 human UAT

## Decision

Do not treat `gigai 0.1.4` as the meaningful final UAT candidate. The next
candidate must close the foundational product gaps represented by:

- [TD-0006](TD-0006-evaluation-taxonomy-and-behavioral-evals.md) — unified
  evaluation tiers and behavioral eval framework;
- [TD-0007](TD-0007-central-role-registry.md) — namespaced, extensible role
  registry; and
- [TD-0008](TD-0008-browser-first-create-and-model-setup.md) — setup/model
  selection and browser-first `create` flow.

G26 automated evidence and the G27 contract package may continue to provide
implementation input, but G24 human UAT should begin only against a v0.1.5
candidate that passes this gate.

## Required candidate evidence

1. Unit/contract, integration, installed E2E, and behavioral eval commands are
   separately named and reported.
2. G26/G27 eval suites produce versioned, sanitized reports with real negative
   cases; plumbing-only reports are not labeled behavioral passes.
3. Role references are centrally registered and validated at the boundaries
   touched by the candidate.
4. `gigai setup` presents model options and truthful readiness.
5. `gigai create tailor-resume-for-job` opens the HTMX flow after normal target
   setup without implementation-facing flags.
6. Reinstall/upgrade preserves existing local authority and the candidate's
   installed-resource verification passes.
7. Only after these checks pass does G24 run the human SQLite/workpad/UAT
   protocol.
