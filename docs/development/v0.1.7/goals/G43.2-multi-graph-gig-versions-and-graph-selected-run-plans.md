# G43.2 — Multi-Graph Gig Versions and Graph-Selected Run Plans

**Version:** v0.1.7
**Status:** Proposed — contract defined; not activated
**Depends on:** G43 and completed G43.1 provider-review dogfood
**Unblocks:** graph-aware G44, G45.2 source bindings, G46 Job Search Lifecycle

## Outcome

G43.2 makes one approved Gig version a bounded family of independently
selectable Goal Graphs. It preserves the existing approval and Run boundaries:

```text
approved Gig version
  -> immutable Graph Set
       -> one selected graph
            -> sealed Run Plan
                 -> one directly confirmed Run
```

It is not a scheduler, journey engine, graph composer, capability grant, or
second intent router. A Run selects one graph only. Graph changes create a new
approved Gig version; no graph has an independent active pointer or version
counter.

## Graph Set and descriptor contract

`gig-graph-set.schema.json` has schema ID
`urn:gigai:schema:gig-graph-set:1`. It is a strict, content-addressed artifact
with `schema_version`, `graph_set_id`, `gig_id`, `graphs`, `created_at`, and
`created_by`. `graph_set_id` matches `graph_set_<uuidv4>`.

Each `graphs` entry is a strict Graph Descriptor with:

- `graph_id`, purpose, aliases, and a safe routing summary;
- one Goal Graph artifact reference;
- input, output, and permitted-reference contracts;
- effect policy and capability requirements;
- provider/model eligibility policy, without a concrete configured target,
  credential reference, discovery result, or secret;
- budget ceiling, including a typed `max_source_requests` only when the graph
  declares a bounded deterministic network-read effect;
- review contract, evaluation contract, and completion-evidence contract.

`graph_id` matches `^[a-z][a-z0-9-]{0,63}$`; aliases use the same pattern and
cannot collide with any graph ID or another alias. Every reference is an exact
common artifact reference. The semantic validator rejects duplicate IDs,
aliases, digests, unsafe paths, absent references, a descriptor whose declared
Goal Graph does not agree with its attached contracts, and any graph that widens
the approved Gig-level effect, capability, provider-eligibility, or budget
ceiling.

The Graph Set is sealed by Gig approval. Addition, removal, or any descriptor
or referenced-content change produces a new proposal and approved Gig version.

## Selection record and Run Plan boundary

G43.2 owns `graph-selection-record.schema.json`, schema ID
`urn:gigai:schema:graph-selection-record:1`. A strict selection record has
`schema_version`, `selection_record_id`, `gig_id`, `gig_version`, `graph_set`,
`selected_graph_id`, `selected_graph`, `selection_kind`, `selector`,
`selection_reason`, `routing_evidence_refs`, and `created_at`.

`selection_kind` is exactly `operator_explicit`, `g44_routed`, or
`only_member_default`. `selector` is exactly `kind`, `actor`, `rule_id`, and
`rule_version`; `routing_evidence_refs` is an array of common artifact
references. Its conditional rules are:

| Kind | Required selector | Routing evidence |
|---|---|---|
| `operator_explicit` | operator actor; null rule fields | empty |
| `g44_routed` | `g44_router`; non-null G44 rule ID/version | one or more safe artifact references |
| `only_member_default` | GigAI deterministic selector; null rule fields | empty |

No other selection source is valid. G44 later produces the `g44_routed` form;
it does not own this schema. The selection record is evidence, not Run
authority.

G43.2 adds versioned proposal, active-version, Run Plan, Run-handoff, Run
manifest, Run-details, comparison, portability, and projection readers/writers
as needed. A multi-graph Plan seals the Graph Set reference,
`selected_graph_id`, selected Graph Descriptor/Goal Graph references, and one
selection-record reference. It rejects every mismatch. With more than one
graph, missing selection returns `graph_selection_required`; the planner does
not inspect request prose, re-run G44, or guess.

Historical v1 proposal, active-version, Plan, Run, and journal bytes remain
unchanged. Readers may project them as a virtual one-graph Graph Set for
inspection only; no migration rewrites an old record or makes the projection a
new authority record.

## Compatibility and evidence

G43.2 validates the complete authority chain:

```text
proposal -> approved Gig version -> Graph Set -> selected graph
  -> sealed Run Plan -> direct-confirmed Run -> projections
```

Its fixtures include structural Career and Stock Graph Sets but make no claim
that those domain workflows execute. Tests cover descriptor and selection-record
schema/semantic rejection, shared-policy widening attempts, graph/Graph-Set
mismatch, all selection kinds, missing multi-graph selection, v1 read-only
compatibility, and Run-manifest reconstruction.

## Stop conditions

Stop if a graph can be selected without the approved Gig version, a graph can
widen shared policy, a v1 record is rewritten, a G44 routing result can become
Run authority, or another graph/Prior Run becomes input without an explicit
digest-pinned artifact binding.
