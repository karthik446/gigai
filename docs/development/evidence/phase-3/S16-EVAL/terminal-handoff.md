# S16-EVAL terminal handoff

S16-EVAL is complete as a research and contract-design spike.

G18 is a hard dependent. Before provider comparison or candidate judge
selection is accepted, G18 must cite this corpus manifest, ground-truth
protocol, assertion matrix, mutation report, and fixed calibration bar, then
run its selected judge against the immutable Final Held-Out Acceptance set.
G18 may not redefine the bar.

G19 is also a hard dependent because its loop verdict can authorize real target
consequences. It must cite the same evidence and must not grant target
mutation authority based on structural loop validity alone.

G22 is conditional: it cites S16-EVAL only where its implementation actually
invokes or evaluates the Review Loop. S22-01 remains authoritative for
proposal-question quality and is not replaced by this spike.

Open boundary: production judge/model selection, live provider execution, and
Final Held-Out Acceptance scoring remain G18 work. Any need for durable runtime
storage of calibration or corpus-label records requires a separate additive
contract amendment.
