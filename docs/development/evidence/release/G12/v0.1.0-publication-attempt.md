# v0.1.0 publication attempt

`v0.1.0` was tagged on `adb27e127b6fcb74ffda8b06257cf8d38f0685f5` on
2026-08-05. Its exact-tag CI, artifact build, provenance attestation, and fresh
wheel/source-distribution smoke checks passed.

TestPyPI publication then failed before upload because the publisher received
the complete `dist/` directory. That directory included `SHA256SUMS`, which is
release evidence rather than a Python distribution; PyPI rejected it as an
unknown distribution format. TestPyPI and PyPI publication jobs were therefore
not run successfully, and no `gigai` distribution was published.

The public `v0.1.0` Git tag remains immutable. The immediate recovery candidate
was `v0.1.1`, whose workflow prepares a package-only publisher directory while
retaining `SHA256SUMS` for attestation and the GitHub Release.
