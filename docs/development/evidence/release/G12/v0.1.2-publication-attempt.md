# v0.1.2 publication attempt

`v0.1.2` was tagged on `708f760c0257b7342b2d7d59583e12b6cc96d43a` on
2026-08-06. Its release workflow stopped in the exact-tag CI gate before
artifact build or either package publication.

The Debian 12 offline-container lane exposed a concurrent v1-to-v2 registry
migration race in `test_two_concurrent_migrators_converge`: one process could
validate a transient SQLite schema state and reject it as corrupt. No TestPyPI
or PyPI upload was attempted.

The public `v0.1.2` tag remains immutable. The `v0.1.3` recovery serializes
every existing-registry validation and migration transition with an advisory
lock on the registry parent directory, creates no persistent lock artifact,
and adds a deterministic two-process regression proof for the post-commit
transition boundary.
