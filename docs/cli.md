# GigAI command reference

Generated by `make cli-manual` from `gigai agent-context`; do not edit by hand.
117 commands (schema v1). Agents: run `gigai agent-context --json` for the machine-readable form.

- **effect**: `read` never changes state; `write` may change GigAI state or files (for some commands only with certain options).
- **external**: the strongest thing the command can reach. `none` is offline, `model` may call a model provider (cost, and text leaves this machine), `network` may make other network requests.

## `gigai agent-context`

Print the machine-readable command manual (this file merged with the live Click tree).

`gigai agent-context [OPTIONS]`

effect: `read` · external: `none` · output: One summary line; --json emits the full manual (schemaVersion, commandCount, commands).

Example:

```sh
gigai agent-context
gigai agent-context --json
```

Offline; reads only the packaged manifest and the command tree.
