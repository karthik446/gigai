# Model-debate experiment

`model-debate` is a dependency-free trusted-host experiment for bounded
Codex-to-Claude review handoffs. It is retained as research evidence, not as a
GigAI product command or containment boundary.

The raw proof transcript was intentionally excluded from the public repository:
it contained workstation paths and references to an unrelated source checkout.
The executable remains available for inspection, while any future public
evidence must be regenerated with repository-relative provenance.
