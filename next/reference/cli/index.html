CLI reference

103 commands (schema v1). Agents: run gigai agent-context --json for the machine-readable form.

  • effect: read never changes state; write may change GigAI state or files (for some commands only with certain options).
  • external: the strongest thing the command can reach. none is offline, model may call a model provider (cost, and text leaves this machine), network may make other network requests.

gigai agent-context

Section titled “gigai agent-context”

Print the machine-readable command manual (this file merged with the live Click tree).

gigai agent-context [OPTIONS]

effect: read · external: none · output: One summary line; –json emits the full manual (schemaVersion, commandCount, commands).

Example:

Offline; reads only the packaged manifest and the command tree.

gigai agent-permissions

Section titled “gigai agent-permissions”

Print a recommended Claude Code permissions snippet (deny reading ~/.gigai, allow the GigAI CLI) for you to apply.

gigai agent-permissions [OPTIONS]

effect: read · external: none · output: A JSON snippet and a short plain explanation on stdout.

Example:

Offline. Prints only; GigAI never edits your agent’s settings.

gigai agent-skill

Section titled “gigai agent-skill”

Print the instructions that teach your AI agent the daily Scout loop (a Claude Code SKILL.md, or an AGENTS.md section).

gigai agent-skill [OPTIONS]

effect: read · external: none · output: The instructions text on stdout; with –out, one line naming the file written.

Example:

Offline. Prints by default; –out writes only the file you name and refuses to replace an existing one without –force. Never writes into an agent’s own folders by itself.
