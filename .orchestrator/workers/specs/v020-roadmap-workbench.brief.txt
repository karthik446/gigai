OPERATOR DECISIONS (2026-09-23, record; do not re-open):
D-A. Product framing: gigai is a personal software workhorse to develop, run and publish MANY gigs (about 10 ideas), all open source. Audience: the operator, plus at most ~5 people. It tracks, runs and uses AIs. Optimize for "add or extend a gig easily" and "run it with one command", not for third-party API stability.
D-B. MONOREPO FOR NOW: gigs live in one repo until there are 4–5 gigs with clear separation, then split. **This amends S21's decision 1 ("Scout moves to its own repo"): fold it into the S21 r1 revision.**
D-C. `gigai <gig> run` (e.g. `gigai scout run`) opens everything for that gig: all its goal graphs and its UI. No manual workpad, binding or config ceremony.
D-D. Secrets: `gigai secrets add exa` prompts for the API key and stores it in the gigai root folder (~/.gigai), where every gig can use it.
D-E. Cost is shown at the gig-dashboard level (search cost etc.).
D-F. gigai has its own UI; each gig has its own UI, added when the gig is running; gigai's server enforces the API rules.
D-G. Python only. Gig data is gig-owned (S21).

EVIDENCE FOR WORKSTREAM 0 (secrets), from the coordinator's reads/greps. Re-verify before citing:
- Home root is ~/.gigai or $GIGAI_HOME: src/gigai/setup.py:47-48. setup.py:199 creates home_root/credentials, which nothing reads or writes (grep).
- ~/.gigai/.env exists (mode 0600) and holds the provider key NAMES (EXA_API_KEY, OPENROUTER_API_KEY, …). Its header says GigAI reads them, but NO code loads .env: the only reference is src/gigai/private_transfer.py:102, which excludes it from transfers. Never read the values.
- Credential refs: config.toml [[credentials]] name/kind/reference. Only kind=environment resolves (src/gigai/credentials.py:55-72); keychain/op/vault validate (:12) but can't resolve.
- Exa bypasses the credential system: src/gigai/scout/find_jobs/exa_client.py:38,66-73 reads os.environ["EXA_API_KEY"] directly. The runbook makes the operator export it by hand: docs/development/v0.1.8/runbooks/M1-find-jobs.md:151,162.
