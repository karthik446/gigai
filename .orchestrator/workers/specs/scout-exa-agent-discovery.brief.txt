FACTS (exa.ai/pricing + exa.ai/docs/reference/agent-api-guide, read 2026-09-24):
- Search $7/1k requests (≤10 results). Agent fixed effort per run: minimal $0.012, low $0.025, medium $0.10, high $0.50, xhigh $1.00. auto/max are metered at $0.10/ACU + $0.005/search, capped by default at $5 (auto) / $20 (max). Monitors $15/1k runs (schedule ≥1h, webhook delivery, dedup of new results). Free tier: $10/month credits.
- Agent: async (poll or SSE), output_schema for structured output, `output.grounding` maps items to source URLs, and the docs recommend `auto` for list building. Fixed effort costs the same per run regardless of exclusions; with auto, a smaller search space should cost less. Either way the win is novelty.
- Monitors are parked: webhook delivery needs a public endpoint and gigai is local-only.
- Scout's exa_client.py already calls Exa's HTTP API with httpx. Use REST for the agent too; don't add the exa_py SDK unless justified. Verify the agent endpoint path from the docs.
- Why: acquire today finds boards via Exa search, and the ATS APIs return ALL of a company's jobs worldwide. The discovery quality (which companies, sponsorship) is the weak part, and sponsorship is unknown on 69/69 rows (see scout-uat-0181-bugs.brief.txt B3). The agent can find sponsorship evidence with sources (H-1B filings, careers pages).
