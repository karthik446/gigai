# Security policy

GigAI is pre-alpha and is not ready to execute untrusted workloads. The current
wheel distributes contract resources; it does not provide a production runtime
or containment boundary.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
private security-advisory channel and include:

- affected revision and files;
- expected and observed behavior;
- reproduction steps or a minimal proof;
- potential authority, privacy, integrity, or availability impact; and
- whether the report includes sensitive data.

Do not include credentials, private workpads, raw provider transcripts, or
personal data in public reports.

## Supported versions

No production version is currently supported. Security fixes target the latest
pre-alpha revision until a release policy is published.
