About the role
Halden Grid sells energy-trading software to 300 utilities. The Infrastructure team keeps 120 services running in two clouds and owns the tools the other teams deploy with.

What you will do
- Operate Kubernetes clusters across AWS and GCP for services with strict availability targets.
- Manage infrastructure as code with Terraform, with policy checks before changes are applied.
- Define SLOs and build burn-rate alerting on Prometheus and Grafana.
- Lead the on-call rotation and incident response, and write the runbooks the rotation uses.
- Build and speed up the CI/CD pipelines that every team deploys through.
- Run load tests before releases to find capacity limits.

Requirements:
- 8+ years in infrastructure, SRE or platform engineering.
- Deep Kubernetes and Terraform experience in production.
- Experience running an on-call rotation.

Nice to have:
- Operating Kafka clusters.
- Distributed tracing with OpenTelemetry.
- GPU autoscaling for model serving.
