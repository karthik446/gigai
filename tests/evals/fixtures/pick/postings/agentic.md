About the role
Corvane Labs builds assistants that complete multi-step back-office work for logistics companies. The Agent Platform team owns the runtime every product team builds on. Agents here prepare claims, correct invoices and draft customer replies, always with a person approving before anything is written to a customer's account.

What you will do
- Design and operate the agent runtime in production: tool calling with typed tool contracts, retries and budgets.
- Build multi-agent workflows in which a planner agent hands work to specialist agents and merges their results.
- Make long agent runs durable: checkpointed state, so a workflow resumes after a crash or a restart.
- Own LLM evaluation: regression suites that score every prompt change against labelled cases before release.
- Build human checkpoints and approval gates before any irreversible action.
- Build retrieval over customer documents with pgvector or a similar vector store.
- Control LLM cost with prompt caching and model routing.

Requirements:
- 10+ years of software engineering, with 2+ years running LLM agents in production.
- Strong Python and TypeScript.
- Experience operating services on Kubernetes.
- A record of leading a team and mentoring senior engineers.

Nice to have:
- Defending agents against prompt injection and unsafe tool use.
- Tracing and replay for agent runs, with token and cost accounting.
- Experience with the Model Context Protocol.
- Open-source work that other developers use.
