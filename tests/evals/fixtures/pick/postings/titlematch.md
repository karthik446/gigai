About the role
Marrowfield Systems sells scheduling software to 900 field-service companies. The Agent Runtime team owns the backend the company's assistants run on: the services, the event stream, the storage and the release checks every product team depends on.

What you will do
- Design and operate the agent runtime our product teams build on, in production.
- Build backend services in Go and Python on Kubernetes that stay available under heavy load.
- Own the event backbone on Kafka that carries every booking.
- Define SLOs with the teams on the platform and reduce customer-visible incidents.
- Manage infrastructure as code with Terraform across clouds and regions.
- Model data on PostgreSQL, including the retrieval workloads behind the assistants.
- Gate every prompt change on an evaluation suite before release.
- Control LLM spend across model providers.

Requirements:
- 8+ years building backend systems, with several years at staff level.
- A record of leading a team and mentoring senior engineers.
- Experience designing public APIs that are safe to retry.

Nice to have:
- Payments or ledger experience.
- Experience running Kafka clusters.
